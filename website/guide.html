Step by step

Download & install

Three steps, a couple of minutes. Here's exactly what you'll see along the way.

1

Download the installer

github.com/sambui-Electron/Overzen/releases
⇩ Overzen-Setup-x.x.x.exe Download

Go to the Releases page on GitHub and download the latest Overzen-Setup-x.x.x.exe file under Assets on the newest release.

Go to Releases
2

Run the installer

Overzen Setup
C:\Users\You\AppData\Local\Programs\Overzen
Create desktop shortcut
Create Start Menu shortcut
Cancel Install

Open the downloaded file and step through the installer — you can change the install location and choose whether to create desktop/Start Menu shortcuts along the way.

! Windows protected your PC Overzen isn't digitally signed yet — click More info, then Run anyway.

(illustrative — actual Windows dialog may look different)

This SmartScreen prompt is expected for open-source apps that aren't code-signed. It's not a sign anything's wrong — click through it to continue.

3

Launch Overzen & pick your AI source

Overzen
Please select a model to start.
Message local AI agent…

⚙ Gear icon in the sidebar → Settings → AI Provider

Open Overzen, click the gear icon in the sidebar, and under AI Provider choose your source:

  • Local — pick a runner (Ollama, LM Studio, llama.cpp Server, Jan) and confirm its port.
  • Cloud API — enter a Base URL, Model name, and API key.

That's it — start chatting, or click the leaf icon to try Zen Mode.

Blocked entirely with no SmartScreen option?

On some systems, Windows' Smart App Control blocks unsigned apps outright, with no "Run anyway" option at all — this is different from and stricter than SmartScreen. If that happens: Windows Security → App & browser control → Smart App Control → turn it off, install and run Overzen, then turn it back on afterward if you'd like.
